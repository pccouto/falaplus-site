# Fala+ — site de apresentação

Página que apresenta a app Fala+ e encaminha para a instalação no Google Play.

- Sem build: abrir `index.html` no browser para ver localmente.
- Publicação: GitHub Pages, branch `main`, pasta raiz.
- Ligação do Google Play: constante `PLAY_URL` em `main.js`.
- Tipos de letra: Baloo 2 e Nunito (licença SIL OFL, ver `assets/fonts/`).
